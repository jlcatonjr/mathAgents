## 1. Methods

- **`triviality_R2` — direct computation.** Split `X := cond A C` by Expansion,
  `P X = P (C ⊓ X) + P (Cᶜ ⊓ X)`. F₁ unfolds to `P (C ⊓ X) / P C = P (C ⊓ A ⊓ C) / P (C ⊓ A) = 1`,
  so `P (C ⊓ X) = P C`; F₂ unfolds to `P (Cᶜ ⊓ X) / P Cᶜ = P (Cᶜ ⊓ A ⊓ C) / P (Cᶜ ⊓ A) = 0`, so
  `P (Cᶜ ⊓ X) = 0`. Add. The provisos come from `hAC`, `hAnC` (with `inf_comm`); `P C, P Cᶜ > 0`
  by monotonicity.
- **`triviality_R3_closed` — reduction to R2.** For `P ∈ K`, condition on `C` and on `Cᶜ` (both in
  `K` by `hclosed`); Stalnaker's Hypothesis at each conditioned function yields F₁ and F₂
  (lemma L6); apply `triviality_R2`. Stalnaker at `P` itself is not used.
- **`triviality_R3_all` — instance of R3:closed** with `K := {P | IsFinAddProb P}`, which is closed
  under ratio conditioning (L7, L8; proved, not assumed).

## 3. Case analysis

No case split on the algebra or on `cond`. The only split is the C / Cᶜ partition inside Expansion.
No denominator is ever zero: every `condProb` is guarded by `hAC`, `hAnC`, L4 or `hA`.

## 5. Risks

1. **Imports.** The file imports only `Mathlib.Order.BooleanAlgebra.Basic` and
   `Mathlib.Basic.Real.Basic` (the current path; `Mathlib.Data.Real.Basic` is a deprecated module).
   `linarith`, `field_simp` and `div_le_one_of_le₀` may not be in scope. Put Aux in a separate file
   with its own imports, or decide whether adding imports to the approved file touches its fingerprint.
2. **Beta reduction.** `(fun X => condProb P X B) Y` must be unfolded (`simp only [condProb]`,
   `show`) before the division rewrites fire in L6 and L7.
3. **Real division.** Every `div_self` / `div_eq_one_iff_eq` needs an explicit `≠ 0` (`hpos.ne'`);
   prefer these rewrites to `field_simp`.
4. **Set-builder membership.** L8 and R3:all need `Set.mem_setOf_eq`.
5. **Lattice rewriting.** Reassociating `⊓` (L5a, L5b, L6) can loop under `simp`; use explicit
   `inf_assoc` / `inf_right_comm` or `ac_rfl`.
