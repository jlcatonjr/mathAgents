# mathAgents — Decisions Summary

This is the public summary of the mathAgents decision charter. The full charter is kept in the project's archived private repository. Each row here keeps the charter's decision number (D1, D14a, D15a and so on), so any reference to a decision anywhere in this repository resolves to a row below. The clarifications C1–C4 are listed at the end for the same reason.

The charter changes only by new dated entries, never by editing old ones, and this summary follows the same rule. "Superseded by" means a later decision replaced the row. "Amended by" means a later decision changed part of it. The paths are where each decision takes effect in this repository. People are named only by their role: the operator, a collaborator, a co-approver, or the AgenticCapital owner.
