# Codex harness

`.codex/agents/*.toml` are OpenAI Codex custom agents **generated by agentteams** from the
canonical team in `.github/agents/`. Do not hand-edit them. Edit the canonical agent file (or
`brief.json` and re-render), then regenerate:

```bash
agentteams --interop-from .github/agents --framework codex --output . --yes
```

- Codex loads only `.codex/agents/**/*.toml`; the `name` key inside each file is authoritative.
- `sandbox_mode = "read-only"` (the six auditor roles) is a default, not a ceiling: subagents
  inherit the parent session's sandbox. Declared tool lists are self-imposed limits that Codex does
  not enforce.
- The repo-root `AGENTS.md` is shared with the Goose bridge; the Codex adapter never overwrites it.
- Neither `researchteam update` nor `researchteam materialize` refreshes this directory. Rerun the
  command above after any render.
- `scripts/check_render_consistency.sh` checks that this directory has one TOML per canonical
  agent and that every file parses.
